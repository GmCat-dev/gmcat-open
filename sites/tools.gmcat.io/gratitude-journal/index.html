    Where are my entries stored?

    Only in this browser's local storage on this device. GmCat cannot read or recover them.

    Will entries appear on my other devices?

    No. There is no account or cloud sync, which keeps the journal private but means entries stay on this browser.

    How do I remove everything?

    Use “Delete all entries” below the list. Clearing this browser's site data also removes the journal.
