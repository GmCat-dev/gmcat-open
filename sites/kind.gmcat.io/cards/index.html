No account, no upload, no saved message. Shared links contain the artwork, card type and message you choose.

Why the long link?

Your own words travel inside the link itself, so GmCat never stores your message on its servers. The longer the message, the longer the link. Anyone with the link can read the card, so send it only to the person it is for.
