# Reporting a security or privacy problem

Thank you for helping keep GmCat's visitors safe.

**Please don't open a public Issue for security or privacy problems.** Instead, use GitHub's private reporting:
go to the **Security** tab of this repository and choose **Report a vulnerability**. Only the GmCat team can see it.

Helpful things to include: which site and page, what you did, what happened, and what you expected.

We'll reply as soon as we can, fix real problems quickly, and thank you publicly if you'd like.

Please don't access other people's data, overload the sites, or test anything that could hurt visitors.
